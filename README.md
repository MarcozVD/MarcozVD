## 🚀 What I'm working on

### ⚡ FocusFlow

I'm currently building **FocusFlow**, a desktop productivity and calendar application designed around the idea of an **AI Personal Time Manager**.

The goal isn't just to have another calendar.

FocusFlow is designed to understand the user's schedule, tasks and context, and help make better decisions about **how their time should be organized**.

**Tech stack:**

`React` · `Electron` · `Node.js` · `JavaScript` · `AI APIs`

Some of the concepts I'm exploring:

* 🤖 AI-powered scheduling
* 📧 Email → calendar intelligence
* 🧠 Context-aware task management
* 🔔 Smart notifications
* 📅 Calendar & agenda systems
* ⚡ Desktop applications
* 🎨 Neumorphic UI/UX
* 🧩 AI agent orchestration
